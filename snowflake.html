Axon Manufacturing Pipeline

Azure Blob Storage to Snowflake Bronze / Silver / Gold

Manufacturing environments generate data across disconnected systems. Supplier records, production logs, and equipment telemetry do not arrive in a format ready for analysis. I built a pipeline to normalize all of it into a single queryable layer.

Architecture: Raw CSV files land in Azure Blob Storage and flow into a Bronze / Silver / Gold medallion architecture in Snowflake. Bronze holds source data exactly as received. Silver applies transformations: UNPIVOT for metric reshaping, LATERAL FLATTEN for JSON device telemetry, surrogate key generation for dimensional modeling. Gold delivers an analytics-ready supplier scorecard and quality trend layer.

Key Output: A production-grade Snowflake warehouse covering supplier delivery performance, defect rates, and downtime contribution by vendor and period.

Minimum Wage Compliance Model

Azure Blob Storage to Snowflake to Power BI — Professional Build

The benefits in establishing data pipelines for real-time updates have been a must in my experience. Often times, it enabled proactive workforce management and continuous compliance monitoring.

Minimum wage law changes at the state and local level created ongoing exposure risk across multiple jurisdictions. I built a compliance model that tracked every active employee against applicable minimums by jurisdiction, including city-level overrides for California. Raw payroll data landed from Azure Blob Storage into Bronze, moved through transformation in Silver, and materialized in Gold for Power BI reporting.

Architecture: Bronze held raw CSV exactly as received, intentional data quality issues included. Silver applied TRY_TO_DOUBLE to strip dollar-sign and comma formatting, CASE statements to normalize job class variants, and a UNPIVOT via UNION ALL converting three rate period columns per jurisdiction into one row per period. Remote employees were resolved to work state via COALESCE. A 5% buffer flagged At Risk employees before breach, not after.

Gold layer: Two materialized mart tables. MART_COMPLIANCE_CURRENT gave one row per active employee with compliance status and annualized exposure. MART_COMPLIANCE_UPCOMING gave forward-looking rows per employee per upcoming rate period. Power BI connected to Gold only.

Key Output: A monthly compliance dashboard surfacing exposure by jurisdiction, title, and employee — with enough lead time to act before effective dates hit.

Snowpipe with AWS S3

Automated Pipeline Ingestion from AWS S3 to Snowflake

I built and implemented a data pipeline that integrated AWS S3 with Snowflake to detect file uploads and process both structured and unstructured data for real-time warehouse updates.

Goal: Automating updates with additions to the dataset.

AWS S3 Buckets and IAM provided the storage and secure connection. Data objects were built in Snowflake to receive and stage data uploads.

These objects include databases, schemas, and tables as the endpoints.

The pipeline streamed updates in the event of new uploads, creating a real-time feed for newly generated records. A similar setup provisioned continuous monitoring of workforce wages and data integrity within our HCM.
