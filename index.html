SR Data Analyst / Analytics Engineer

Manufacturing Operations • Workforce Analytics • Risk & Compliance • FP&A • Supply Chain

I have spent five years building analytics for organizations that manage large, distributed workforces, and four years before that as a Controls Engineer working across industrial control systems. Starting on the engineering side changed how I approach data work. I think about the architecture first and the output second, because a report is only as good as the system feeding it.

These days I work in manufacturing operations analytics, which is where both halves of that background finally landed in the same job. The projects here cover the full stack: SQL transformations, Snowflake pipelines built on Azure Blob Storage and AWS S3, Power BI dashboards across a range of business domains, and Tableau visualizations. Data Transformation

Most of the work in any analysis happens before the analysis starts. These projects cover cleaning and transformation across operations, supply chain, and workforce data. The Operations Analytics build is the fullest example, running from data quality profiling through window functions and CTEs to a structure reporting can actually sit on.

Pipelines are what make reporting hold up over time. These builds use medallion architecture on Azure Blob Storage, Bronze through Gold. The Compliance Model ran every month, carrying data from ingestion all the way to a live Power BI layer with nobody touching it in between.
